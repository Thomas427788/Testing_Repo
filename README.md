# Embedded-Systems
Advanced Embedded Systems project for Spring 2026. System to make an automated graphene creation device.

To initiate the GUI:

1. Navigate to http://localhost:3000 on a separate web browser on a computer that will be SSHd into the Raspberry Pi.

2. Begin the node.js server by typing 'npm start' into the command line.

3. The separate web browser should populate with the server.
